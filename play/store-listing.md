# Store listing draft

## App name

Focus Wall

## Short description

Set a daily boundary for Reels and Shorts while keeping useful social features.

## Full description

Focus Wall helps you stay connected without falling into endless short-video feeds.

Choose a daily budget from 0 to 60 minutes. It auto-arms at midnight and repeats until you schedule a different future limit; changing tomorrow’s limit never adds time today. Focus Wall measures time only when it confidently detects supported Instagram Reels or YouTube Shorts surfaces. Instagram Home, DMs, Stories, notifications, posts, profiles, and search remain available. YouTube Home, search, subscriptions, and regular videos remain available.

Focus Wall is local-first:

- No account or social-media login
- No ads or analytics
- No cloud database
- No reading or collection of messages, passwords, media, or screen text
- Local, clearable compatibility diagnostics
- Explicit Accessibility disclosure, consent, and withdrawal

Compatibility depends on the installed Instagram and YouTube versions. Focus Wall safely does nothing on versions it has not verified and provides an in-app compatibility screen.

Focus Wall uses Android Accessibility solely to distinguish supported Reels and Shorts surfaces from allowed parts of the same apps, measure the user-selected local daily limit, and show a limit card. The service never performs gestures or changes settings.

Focus Wall is independent and is not affiliated with, endorsed by, or sponsored by Meta, Instagram, Google, or YouTube. It is an attention-management utility, not parental-control, medical, or mental-health treatment software.
